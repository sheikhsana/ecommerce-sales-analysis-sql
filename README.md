# E-commerce Sales Analysis using SQL

## Project Overview

This project focuses on analyzing e-commerce sales data using SQL and MySQL.

The purpose of this project is to understand sales performance, profit, customers, products, cities, categories, payment methods, and order status.

## Objectives

* Analyze overall sales and profit
* Identify top-performing products
* Analyze sales and profit by category
* Analyze city-wise sales and profit
* Analyze monthly sales and profit
* Analyze payment methods
* Analyze order status
* Identify top customers
* Calculate overall profit margin

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## SQL Concepts Used

* SELECT
* SUM()
* COUNT()
* COUNT(DISTINCT)
* AVG()
* ROUND()
* GROUP BY
* ORDER BY
* LIMIT
* YEAR()
* MONTH()

## Analysis Performed

### 1. Overall Business Analysis

Calculated total orders, total sales, total cost, total profit, and average order value.

### 2. City-wise Analysis

Analyzed sales, profit, and number of orders for different cities.

### 3. Category-wise Analysis

Compared sales and profit across different product categories.

### 4. Monthly Analysis

Analyzed sales and profit based on year and month.

### 5. Product Analysis

Identified the top products based on sales and profit.

### 6. Payment Method Analysis

Analyzed sales and profit based on different payment methods.

### 7. Order Status Analysis

Analyzed orders, sales, and profit according to order status.

### 8. Customer Analysis

Identified customers with the highest sales and analyzed their order performance.

### 9. Profit Margin Analysis

Calculated the overall profit margin using total sales and total profit.

## Project Files

* `ecommerce_analysis.sql` — Contains all SQL queries used for the analysis.
* `README.md` — Contains the project description, objectives, tools, and analysis details.

## Conclusion

This project demonstrates how SQL can be used to analyze e-commerce data and generate meaningful business insights from sales data.

The analysis helps understand product performance, customer behavior, sales trends, profitability, and overall business performance.
